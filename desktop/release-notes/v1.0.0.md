# DeterminFlow v1.0.0

`zhijianmengrao/xs2` fork 的首个正式版本。基线为上游
[alikon-art/DeterminFlow](https://github.com/alikon-art/DeterminFlow) v1.1.1，
版本号重置为 1.0.0 作为本 fork 自有版本线的起点；桌面更新分发自托管到
**本仓库 GitHub Releases**。

## 本版要点

- **桌面自动更新自托管**：更新源（endpoints）指向本仓库 Releases，
  latest.json 内的安装器下载链接同样指向本仓库；更新包使用本仓库自有的
  minisign 公钥验签。上游 R2/Gitee 分发源与本 fork 公钥不匹配，已不参与
  更新（fail-closed，验签失败即拒绝）。
- **维护修复（R15–R30，B1–B18）**：HTTP 500 逃逸、幻影目录数据损坏、
  409 谎报占用、supervisor 竞态、CI 审计脚本编码崩溃等 18 个编号缺陷；
  Windows 保留设备名（CON/NUL/COM1 等）在路径面与标识符面统一拒绝，
  杜绝跨平台配置在 Windows 上永久损坏；executor 临时目录钉位
  `data/system/executor-runtimes`。
- **人味（humanware）工具链 UI 接线收官**：score-content / score-chapter /
  check-dialogue 等五端点全部有页面消费方；4xx 错误信息人因化透传 CLI 拒因。
- **质量基线**：后端 1826 条测试（High-IL 权威口径）全绿、前端 439 条全绿；
  CI 四 job（backend / windows-backend / frontend / container-config）与
  桌面构建流水线全绿。

## 安装与升级

| 平台 | Core | Full |
|---|---|---|
| Windows x64 | `DeterminFlow_1.0.0_x64-setup.exe` | `DeterminFlow_1.0.0_x64-full-setup.exe` |
| macOS Apple Silicon | `DeterminFlow_1.0.0_aarch64.dmg` | `DeterminFlow_1.0.0_aarch64-full.dmg` |

Core 不捆绑插件。Full 内置 `bishu-novel 0.2.2`、`public-api 0.1.37`。

- **Windows 自动更新通道为 Core 安装器**：安装本 fork 构建的客户端后可在
  应用内检查更新；本 fork 此前未发布过任何版本，因此不存在旧版升级路径。
- **上游原版（alikon-art）客户端不会发现本版本**——分发地址与签名体系
  均不同，请下载上方安装包全新安装；用户数据与插件目录互不冲突。
- macOS 安装包为 ad-hoc 签名、未经 Apple 公证（与上游一致）：首次打开若被
  系统阻止，请在「系统设置 → 隐私与安全性」选择「仍要打开」并确认。
  macOS 不提供自动更新，请下载 DMG 手动升级。
- 升级保留已有用户数据和插件；Full 不覆盖已安装插件，请在插件页检查更新
  并重启。
