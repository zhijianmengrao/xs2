# DeterminFlow v1.1.1

本次更新增加内置社区插件源，并同步设置分类、会话引用和插件安装确认。

## 新增能力

- 社区插件：内置 [`DeterminFlow-Community-Plugins`](https://github.com/alikon-art/DeterminFlow-Community-Plugins)，与官方插件仓库分开。进入目录只表示结构与既定检查通过，不是官方安全背书。
- 安装确认：从社区或自行添加的仓库安装插件前，会弹出同机同权限风险对话框；官方仓库仍直接安装。
- 仓库名称：官方与社区源显示为「DeterminFlow 官方插件」「DeterminFlow 社区插件」。
- 设置页按外观、模型、压缩、插件、记忆和工作区接口分栏保存。
- 输入框可用 `@` 引用 Prompt、Agent、Skill、Rule、Workflow 和会话；会话侧栏支持本机置顶。
- 资源广场支持单个 Skill 的多文件包。
- Core 补齐长期记忆和工作区宿主接口。没有对应插件时，这些接口保持空闲。

## 修复与改进

- 插件页刷新远程目录时，不再把进行中的空结果显示成没有仓库。

## 安装与升级

| 平台 | Core | Full |
|---|---|---|
| Windows x64 | `DeterminFlow_1.1.1_x64-setup.exe` | `DeterminFlow_1.1.1_x64-full-setup.exe` |
| macOS Apple Silicon | `DeterminFlow_1.1.1_aarch64.dmg` | `DeterminFlow_1.1.1_aarch64-full.dmg` |

Core 不捆绑插件。Full 内置 `bishu-novel 0.2.2`、`public-api 0.1.37`。
升级保留已有用户数据和插件；Full 不覆盖已安装插件，请在插件页检查更新并重启。

macOS 安装包尚未经过 Apple 公证。首次打开若被系统阻止，请在“系统设置 → 隐私与安全性”中
选择“仍要打开”并确认。当前不提供 macOS 自动更新，请下载安装包手动升级。
