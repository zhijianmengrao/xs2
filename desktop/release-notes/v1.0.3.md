# DeterminFlow v1.0.3（fork）

fork 第四个版本：工作流运行画像落地 + 一批「幻影目录 / 说谎返回」修复。

## 修复：数据面诚实化

- **B19**：工作流冻结失败不再误报 404，结构化透出真实原因。
- **B20**：小说清单损坏不再静默重置整书。
- **B21**：未知参数键由 404 改为 **422 结构化拒因**。
- **B24**：novel 面 workspace 覆盖改为白名单，越界不再静默建目录、不再
  谎报 0% 书。
- **B26 / B28**：console 与 workflow 的读端点不再「查询即建目录」——
  幻影工作区诚实返回 404。
- **B29**：preflight 暂存钉到 `BASE_DIR`，资源复制目标长路径化。
- 工作台进度诚实化：损坏清单显式提示；纯 API 跑不再假装 0%。

## 新增：工作流运行画像

- 供应商失败率画像：按阶段聚合尝试 / 失败 / 错误分类，新增只读的
  `run-profile` 端点。
- `run-profile` 支持 `?run_id=` 查询历史 run。
- 任务执行视图新增「运行画像」抽屉：逐阶段尝试、失败与错误分类可视化。
- 画像支持跨 run 对比视图。

## 稳定性

- **R66**：执行器终态落盘后立即摘除运行标记，控制闸门不再在 Session
  收尾窗口误报 `node_control_conflict`。
- 端口分配 TOCTOU 根治；错误分类分层。
- 循环节点轮次语义收敛；失败率与样本量闸门接入 CI（内部质量面）。
- 移除死通道遗留的 3 个孤儿依赖（`futures-util` / `reqwest` /
  `semver`）。

## 分发

- **R2 公网域改为必须显式配置**：未设置 `R2_PUBLIC_BASE_URL` 时发布
  步骤直接失败，不再内置任何回落域名（旧默认值指向上游站点）。
- **发行说明归档**：上游 v1.0.3–v1.1.1 的日志移入
  `desktop/release-notes/upstream/`，本 fork 发行线只保留 1.0.x。
- Windows 自动更新仍为**本仓库 GitHub Releases 单源**（v1.0.2 起），
  清单经 minisign ed25519 验签后才安装。
- macOS 仍为 **ad-hoc 签名、无自动更新**；升级请手动下载 DMG 覆盖安装。

## 安装与升级

| 平台 | Core | Full |
|---|---|---|
| Windows x64 | `DeterminFlow_1.0.3_x64-setup.exe` | `DeterminFlow_1.0.3_x64-full-setup.exe` |
| macOS Apple Silicon | `DeterminFlow_1.0.3_aarch64.dmg` | `DeterminFlow_1.0.3_aarch64-full.dmg` |

- 已安装 v1.0.0–v1.0.2 的 Windows 用户可在应用内检查更新（Core 通道，
  验签后自动安装），本次会提示 1.0.3。
- 其他平台请下载对应安装包覆盖安装；用户数据与已装插件保留。
- Core 不捆绑插件（插件源默认指向 XS2 官方库）；Full 内置锁定的官方
  插件快照。
- macOS 为 ad-hoc 签名（未经公证），首次打开需在「系统设置 → 隐私与
  安全性」选择「仍要打开」。
