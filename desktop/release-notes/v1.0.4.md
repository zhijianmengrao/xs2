# DeterminFlow v1.0.4（fork）

fork 第五个版本：XS2 Novel Flywheel 内置化 + 免 Git 插件同步修复。

## 新增：XS2 Novel Flywheel 内置

- `xs2-novel-flywheel`（0.1.16）随安装包分发在 `builtin-plugins/`，
  首次启动自动装入 PluginStore 并写入启用列表，**无需安装、无需联网**。
- Core 与 Full 都携带该内置插件快照；不再需要用户克隆插件仓库，也不再
  依赖构建机上的 Git。
- 插件管理页仍可正常查看、启用/停用；后续可从随包副本更新。

## 修复：无 Git 环境插件库同步

- Linux 上未安装 `git` 时，本地插件目录现在直接读取
  `plugin-repository.toml` 与 `extension.toml`，不再调用 Git。
- 本地目录安装改为直接复制（内容摘要作为 revision），`install/update`
  在无 Git 环境下可用。
- Git 缺失时的报错改为「未找到 git 可执行文件：请安装 git，或改用本地
  插件目录」，不再误报「Plugin 仓库目录暂不可用」。
- 修复 Windows 上 Git `core.symlinks=false` 导致越界符号链接漏检的问题：
  现在直接校验 Git 树中的 symlink 条目。

## 清理

- 移除 `plugin-sources.json` 中残留的 Windows 盘符本地源
  （`file:///F:/...`）及第三方自定义源。
- 默认只启用 `xs2-novel-flywheel`；其他插件（`apocalypse-writer`、
  `humanizer-zh`、`lieflat-less-ai-tone`、`oh-story`、`webnovel-writer`、
  `bishu-novel`）不再随软件安装或默认启用。

## 分发

- Windows 自动更新仍为**本仓库 GitHub Releases 单源**，清单经 minisign
  ed25519 验签后才安装。
- macOS 仍为 **ad-hoc 签名、无自动更新**；升级请手动下载 DMG 覆盖安装。

## 安装与升级

| 平台 | Core | Full |
|---|---|---|
| Windows x64 | `DeterminFlow_1.0.4_x64-setup.exe` | `DeterminFlow_1.0.4_x64-full-setup.exe` |
| macOS Apple Silicon | `DeterminFlow_1.0.4_aarch64.dmg` | `DeterminFlow_1.0.4_aarch64-full.dmg` |

- 已安装 v1.0.0–v1.0.3 的 Windows 用户可在应用内检查更新（Core 通道，
  验签后自动安装），本次会提示 1.0.4。
- 其他平台请下载对应安装包覆盖安装；用户数据与插件配置保留。
- Core / Full 均内置 XS2 Novel Flywheel，安装后即可使用。
- macOS 为 ad-hoc 签名（未经公证），首次打开需在「系统设置 → 隐私与
  安全性」选择「仍要打开」。
