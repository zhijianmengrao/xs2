# DeterminFlow v1.0.2（fork）

fork 第三个版本：桌面更新与插件安装双治本 + 插件分发收敛为自有渠道。

## 修复：桌面更新

- **更新误报根治**：更新检查收敛为仅本仓库 GitHub Releases 单源。此前
  updater 同时探测上游 R2 与 Gitee 通道，上游残留的更高版本号
  （1.1.1 / v1.0.10）会穿透成"发现新版本"误报且下载必然验签失败；现已
  彻底移除上游通道（Windows 与 macOS 同步），发布清单仍经 minisign
  ed25519 验签后安装。
- **更新入口可见**：设置分区改名「桌面与更新」，更新通知的"查看更新"
  按钮直达该分区。

## 修复：插件安装（Windows 长路径）

- 解决安装含深层资源的插件（如 xs2-novel-flywheel 的 writing-dna-skill
  vendor 树）时报 `WinError 3 系统找不到指定的路径` 的问题：插件安装、
  校验、启用的全链路文件操作改走 `\\?\` 扩展路径，git 检出启用
  `core.longpaths`，发布快照目录改用短名（用户机首装路径降至约 219
  字符，远离 MAX_PATH 边界）。

## 分发收敛

- **官方插件库切换**为自有仓库 [zhijianmengrao/xs2-plugins]
  (https://github.com/zhijianmengrao/xs2-plugins)，移除上游社区源与
  R2 registry。
- **Full 捆绑插件收敛**：仅内置 `xs2-novel-flywheel 0.1.13`（首启默认
  安装并启用）；移除 `bishu-novel` 与 `public-api`（公益模型）。已安装
  这两个插件的用户升级后本地插件保留，但其官方源不再分发更新。

## 稳定性

- 工作流执行器终止脚本进程树改为直读 `/proc`（不再依赖外部 `ps`，
  消除无 procps 环境下孙进程成为孤儿的风险）。
- 质量基线：CI 四 job 全绿（backend / windows-backend / frontend /
  container-config），桌面 core/full 流水线全绿。

## 安装与升级

| 平台 | Core | Full |
|---|---|---|
| Windows x64 | `DeterminFlow_1.0.2_x64-setup.exe` | `DeterminFlow_1.0.2_x64-full-setup.exe` |
| macOS Apple Silicon | `DeterminFlow_1.0.2_aarch64.dmg` | `DeterminFlow_1.0.2_aarch64-full.dmg` |

- 已安装 v1.0.0/v1.0.1 的 Windows 用户可在应用内检查更新（Core 通道，
  验签后自动安装）——本次将真实提示 1.0.2；其他平台请下载对应安装包
  覆盖安装，用户数据与已装插件保留。
- Core 不捆绑插件（插件源已默认指向 XS2 官方库）；Full 内置
  `xs2-novel-flywheel 0.1.13` 并默认启用。
- macOS 为 ad-hoc 签名（未经公证），首次打开需在「系统设置 → 隐私与
  安全性」选择「仍要打开」；macOS 无自动更新。
