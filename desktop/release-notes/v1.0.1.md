# DeterminFlow v1.0.1（fork）

fork 第二个版本（**暂定最终版**，项目收官）。承接 v1.0.0 的分发与更新体系，
收尾三块：人味工具历史持久化、发版流程固化、创作管线实战验证。

## 新增能力

- **人味工具历史记录**：试评（score-content）、对话检查（check-dialogue）、
  章节评分（score-chapter）的结果按工作区持久保存在本机浏览器
  （localStorage，最近 20 条），刷新/重启后仍可查看，支持一键清空；
  隐私模式等存储受限环境自动降级为无历史，不影响主功能。
- **发版 SOP 与验收脚本**：`docs/RELEASE_SOP.md` 固化「六处版本同步 →
  release-notes → tag → 流水线 → 验收」全流程；
  `scripts/verify_release.py` 一键验收发布产物（sha256、minisign ed25519
  端到端验签、latest.json 端点三项校验）。

## 验证与改进

- 小说创作全流程实战验证：世界观构建管线（多 agent 节点真实 LLM 产出
  7,749 字结构化世界观）、失败-重试语义、步骤推进 UX、模拟读者评估
  （reader-sim 工作流 → 报告 → UI 渲染 → 返修入口）全链路通过。
- 已知模型层建议：思维链全开 + 高推理强度 + 65536 token 上限的组合在
  部分第三方模型上可能跑飞（生成打满上限被截断）；任务会以明确报错失败、
  重试即可；追求稳定可下调 `max_completion_tokens` 或关闭 thinking。
- 质量基线：后端 1826 条（High-IL 权威）全绿、前端 447 条全绿、CI 四 job
  与桌面流水线全绿。

## 安装与升级

| 平台 | Core | Full |
|---|---|---|
| Windows x64 | `DeterminFlow_1.0.1_x64-setup.exe` | `DeterminFlow_1.0.1_x64-full-setup.exe` |
| macOS Apple Silicon | `DeterminFlow_1.0.1_aarch64.dmg` | `DeterminFlow_1.0.1_aarch64-full.dmg` |

- 已安装 v1.0.0 的 Windows 用户可在应用内直接检查更新（Core 通道，验签后
  自动安装）；其他平台请下载对应安装包覆盖安装，用户数据与插件保留。
- Core 不捆绑插件；Full 内置 `bishu-novel 0.2.2`、`public-api 0.1.37`。
- macOS 为 ad-hoc 签名（未经公证），首次打开需在「系统设置 → 隐私与安全
  性」选择「仍要打开」；macOS 无自动更新。
