# 小说工作流适配约定（本项目的用户要求优先于上游通用指南）

原始 writing-dna-skill 的分析方法与中文模板在上文保留。本适配用于小说样本分析，不替换现有的写法候选、兼容顾问和显式采用流程。

- 支持一篇短篇全文或长篇章节样本。上游的“至少20篇文章”是完整作者风格研究的建议，不作为本工作流的硬性门槛。少量样本必须标注暂定结论。
- short_full：区分前几百字的开篇钩子、全文冲突递进与结尾回收。serial_chapters：区分前1～3章的开局、章首章末与跨章递进。未导入完整长篇时不得推断整书结局和全部伏笔回收。
- L1 以本地实际统计为准，高频字串不能冒充名词或动词词频。字体混淆影响词汇分析时降低置信度，不猜测字形。
- L2 分析叙事组织与冲突因果；L3～L5 适配为视角、信息披露、意象、角色判断及主题呈现。不得把人物立场等同于真实作者信念。
- 纯文本没有原始图像、字体或网页排版，L6 必须说明未采集、不适用或无法判断，不推测配色、字体和图片内容。
- 每条风格观察和冲突链须提供当前窗口内的原文证据。跨窗口汇总只能使用已校验观察，不能将缺失的前因或后果补成既成事实。
- 冲突链提取目标、前置伏笔、阻碍、行动或解决、代价、新阻碍及其因果联系、回收方式。样本未显示的环节明确写“样本未见”，允许没有冲突链。
- 原文快照及证据仅用于分析和核查。新小说创作只读取用户选择的抽象规则及适配建议，不自动输入来源人物、事件和原句。
- 本书明确设置和统一风格基线优先。没有蒸馏结果时仍可直接原创。风格汇总不修改本书风格基线，不自动勾选任何写法。


## 小说人物扩展
上游五份模板保持原样；另增人物写法.md，分析欲望、矛盾、情绪行为、对话声线、关系变化和配角独立目标，必须有窗口证据。样本不足明确未知，人物机械化作为风险，不复制具体人物。证据目录编号由脚本生成并严格校验原文，避免字体编码造成摘录失真。
