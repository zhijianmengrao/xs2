# 社区版更新

当前正式版为 [v1.0.3](../desktop/release-notes/v1.0.3.md)。v1.0.2 的安装包说明见
[v1.0.2 更新日志](../desktop/release-notes/v1.0.2.md)。

> 本仓库（xs2 fork）自 v1.0.0 起独立编号；下文 v1.0.3–v1.1.1 是**上游
> 社区版**的更新记录，随代码一并继承，原文归档在
> `desktop/release-notes/upstream/`，不属于本仓库的发行线（R241 拍板）。

- 资源广场：发现、发布和审核状态交互，Skill 安装、更新、卸载、来源识别与摘要校验；本地内容来源与线上资源身份分离。
- 统一账户：浏览器授权、状态刷新、取消登录，以及桌面登录完成后的返回唤起。账户与资源广场的托管服务不包含在 Core 源码中。
- 执行可靠性：统一重试预算、恢复超时、活跃任务索引、会话目录与永久 Provider 错误处理。
- 插件管理：独立服务预检、状态刷新、首次启用提示和托管扩展诊断。公益模型作为可选插件分发。
- 界面：统一语义颜色与弹窗、资源详情和发布表单、Skill 更新导航。
- 桌面：登录唤起协议和 macOS 构建支持；保留 Windows 执行器、本地 TCP 身份校验、进程树回收和公开安装包构建锁。

## 2026-09-11 已纳入 v1.1.1

- 设置页改为分类注册表：外观、模型、压缩、插件、记忆和工作区接口分栏保存。
- 资源广场支持单个 Skill 的多文件包。
- 输入框 `@` 引用 Prompt、Agent、Skill、Rule、Workflow 和会话；加号插入 `@`。会话侧栏支持本机置顶。
- 增加内置社区插件源：`https://github.com/alikon-art/DeterminFlow-Community-Plugins.git`，跟踪 `main`。来源标记为社区，安装仍按第三方信任并要求确认同机同权限风险。官方源、Gitee 镜像和 R2 Registry 保持原样。
- Core 补齐长期记忆和工作区的宿主接口、设置项与注册方法。没有记忆插件或工作区插件时，这些接口保持空闲，不会假装已经提供存储或召回。对应插件本身不同步。
- 官方和社区插件仓库显示名改为「DeterminFlow 官方插件」「DeterminFlow 社区插件」。从社区或第三方仓库安装插件时，先弹出风险确认对话框，确认后才提交安装。
- 引导页、Windows 多 Executor、v1.1.0 发行包装和社区默认 Prompt/Rule/Skill 仍以社区已有修改为准。

社区版的默认 Prompt、Rule、Skill、发行版本和官方插件锁独立维护。v1.1.0 及更早的安装包、Tag 和签名保持不变；v1.1.1 以独立 Tag 和安装包发布。
