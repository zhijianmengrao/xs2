## 1. 本轮最重要的一件事：8% 是「突破线」，不是「健康线」

校准不是「再看一眼 8% 顺眼不顺眼」，而是把判据的**操作特征**算出来。n=255 时
`--fail-if-above 8` 的三个判决带是：

| 判决 | 失败次数 k | 观测失败率 |
|---|---|---|
| `normal` | **k ≤ 13** | **≤ 5.10%** |
| `undetermined` | 14 – 28 | 5.49% – 10.98% |
| `exceeds` | **k ≥ 29** | **≥ 11.37%** |

**判 `normal` 的实际门槛是 5.10%，不是 8%。** 8% 只作用于 `exceeds` 那一侧，
而且观测值必须比自己高 3 个百分点以上才敢开口。真实失败率恰为 8% 时
P(判 normal) = **4.9%**、P(判不了) = 91.5%——点估计落在上限上时上界必然高于
上限，任何样本量都如此，这不是缺陷，是精确界的代数性质。

检出侧同样必须写清：2 倍基线（7.84%）的检出率只有 **2.85%**；50% / 80% / 95%
功效分别要真实失败率到 **11.25% / 12.96% / 14.75%**。**它不是漂移探测器**——
2%→7% 这种变化归 `--fail-on-regression`，上限只回答「有没有证据表明突破了
8%」。

## 2. 结论：维持 8%（三条依据，都可复核）

1. **8% ≈ 全历史样本失败率的 95% 上界**：本机 `data/workflows` 全部 40 个 run
   合计 **16/297 = 5.39%，95% 上界 8.07%**。8% 是这个上界的整数化（差 0.07pp）。
2. **低于 8% 的整数在当前样本量下不可用**：
   - ≤ 6.56%（当前快照上界）时，当前数据立刻从 `normal` 变 `undetermined`，
     闸门再也说不出「正常」；
   - **7% 时政策带与回归带逐 k 完全重合**（都是 normal≤10 / exceeds≥26）——
     政策层不再有独立判决，多一层没有增加任何判决力。
3. **高于 8% 只会更钝**：9% 时 10% 真实率的检出率从 26.0% 掉到 10.8%，10% 时
   掉到 3.4%。8% 是「可用区间里最敏感的整数」。

## 3. 候选上限对照（n=255，同一份当前数据）

| 上限 | normal 到 | exceeds 从 | 检出率 @10% | 检出率 @12% | 当前数据判决 |
|---|---|---|---|---|---|
| 6.00% | 3.14% | 9.02% | 72.9% | 94.5% | **undetermined** |
| 6.50% | 3.53% | 9.41% | 65.3% | 91.8% | **undetermined** |
| 6.92%（回归阈值） | 3.92% | 10.20% | 48.9% | 83.7% | normal |
| 7.00% | 3.92% | 10.20% | 48.9% | 83.7% | normal |
| **8.00%** | **5.10%** | **11.37%** | **26.0%** | **65.0%** | **normal** |
| 9.00% | 5.88% | 12.55% | 10.8% | 42.2% | normal |
| 10.00% | 6.67% | 13.73% | 3.4% | 22.3% | normal |
| 12.00% | 8.24% | 15.69% | 0.3% | 4.7% | normal |

与回归层的排序保持：回归阈值 6.92% 先红于 k≥26（10.20%），政策上限要
k≥29（11.37%），**间隔 3 次失败（1.17pp）**。8% 保住了「回归先开口」。

## 4. 校准顺带产生的两个可执行结论

1. **样本量门槛（数据要求，不是意见）**：想让「normal」覆盖到 6% 的观测值，
   需要约 **475 次尝试**（当前 255）；想让 10% 真实率有 80% 检出率，需要约
   **1221 次尝试**（精确界实算：n=600 → 52.0%、n=800 → 61.0%、n=1000 → 71.6%）。
   在此之前，上限是「有证据才说突破」的保守闸门，不是灵敏探测器。
2. **`_binomial_cdf_le` 的溢出边界按形状记，不按 n 记**：`math.comb(n,k)` 超过
   float 上限时抛 `OverflowError`。实测 **n=1100, k=550（50% 失败率）溢出**；
   本项目形状（k≈4%n）**n=4000 仍可算**（区间 [3.50%, 4.55%]）。当前 255 次
   尝试离任何边界都很远；真到那个量级时是响亮的 traceback，不是静默放行。
   记为独立技术债，本轮不修（范围只做主线）。
