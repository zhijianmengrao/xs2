- **R149 索引 §1 余下两行机械化**：R137 只钉了三行（交接文档 / 用例 /
  写回），L4 钉了判据条数；**「文档体量」与「代码基线」仍手抄**。实测
  体量行 19,408 行 / 1.1 MB；代码基线行 `ea05970`（R146 bot）。判据方向：
  体量行行数 == 磁盘 `HANDOVER_ROUND*.md` 的 `splitlines()` 总和、MB ==
  归一化 UTF-8 字节 / 1 MiB（读文本统一换行，跨平台稳定）；代码基线 sha
  == `history.json` 末条 run 对应的 bot 提交（`git log --grep`），行内
  `R<n>` == bot 提交父提交的轮次。
- **R150 双锁闭包同账**：W8/W9 只钉顶层声明到锁的边，**运行时锁与开发锁
  的闭包之间无人对账**。实测 `requirements.lock` 81 包 ⊆
  `requirements-dev.lock` 84 包，共享 81 包钉版 **0 漂移**；dev-only 3
  （`pytest` / `pluggy` / `iniconfig`）。判据方向：W10 runtime lock ⊆
  dev lock（按名）；W11 共享包钉版逐字相等。当前无漂移，补的是防复发。
- **R151 Python 支持面同账**：实测四处声明不一致——`pyproject
  requires-python >=3.11`、classifiers 3.11/3.12；CI 矩阵 3.11（ubuntu
  backend 与桌面）与 **3.14**（windows-backend 权威）；Dockerfile
  `python:3.12-slim`；README 3.11+。**3.14 是权威 CI，却不在 classifiers**。
  判据方向：CI 矩阵与 Dockerfile 的每个版本 ∈ requires-python 范围且 ∈
  classifiers；README 的下限 == requires-python 下限。修法：补 3.14
  classifier（一次元数据改动）。
