## 2. 问题

R113 已把三种失败形状写进历史：全失败（total 3 / failed 3）、0 场景
（total 0）、重试多次仍失败。但 `check` 的输出是：

```text
| 轮次 | 时间 | 场景 | 重跑 | 重跑率 | 总尝试 |
| r1   | …    | 3    | 0    | 0.0%   | 3      |
```

「失败 3」与「通过 3」在表里完全一样——**记录失败数但不展示，等于下游
从来没有消费过它**。另一处是 0 场景：`latest_total == 0` 落进
「本步没有判定力：历史里没有可读的轮次」，但历史明明可读，只是这一轮
没有场景、重跑率不可计算。

## 3. 改动

`scripts/e2e_retry_history.py::render_trend`：

- 表头/行新增 `失败` 列（`int(entry["failed"])`）；
- 文案三分支：
  - `not rounds`：历史里没有可读的轮次（保持原意）；
  - `latest_total > 0`：原有「1 次重跑 = N 个百分点」；
  - `latest_total == 0`：**「最近一轮 0 个场景，重跑率不可计算（n/a）；
    退出 0 只表示这一轮数据可读，不代表通过。」**

判据边界不动：`check` 仍只校验历史有效性、不判趋势好坏，退出码语义不变；
失败列只展示，不参与任何判决。

## 4. 测试

`tests/test_e2e_retry_history.py`：

- `_metrics(total, retried, failed)` 支持制造失败场景（attempts=1、
  `passed=False`、`first_failure="模拟失败"`），`_entry` 同步透传。
- `test_check_shows_failed_scenarios_in_the_trend_table`：全失败轮
  （3/3/0/0.0%/3）必须出现在 `失败` 列；按列解析而非整行子串。
- `test_check_distinguishes_zero_scenarios_from_an_empty_history`：
  0 场景轮退 0，输出含「最近一轮 0 个场景」「n/a」，且不含
  「没有可读的轮次」。
